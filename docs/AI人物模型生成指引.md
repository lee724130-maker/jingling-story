> 目标：把 Agnes 生成的写实质感人物图，通过腾讯混元3D 转成带动画的 3D 模型，替换现有 Soldier 模型。
> 为什么换平台：Tripo 生成模型需开会员才能下载，已放弃；网页创作平台积分与 API 积分不互通。腾讯混元3D 国内直连、每天免费、能导出 GLB。

---

## 一、先说清楚风险（先看再决定要不要做）

AI 图生 3D 有明显局限，不是"图好看 = 模型好看"：

- **正面可能还原不错，背面/侧面是 AI 推测的**，容易糊、细节丢失
- **骨骼动画质量一般**：可能有穿模、关节变形，自然度不如专业手 K 模型
- **披风、长发、背后箭袋**这类结构最容易出破面（女主 ranger 有背后箭袋，风险更高）
- 当前 Soldier 模型有真实纹理 + 成熟 Idle/Walk/Run 动画，实际游戏表现稳定

**建议**：反正混元3D 免费，先生成一次看实际效果。满意再接入，不满意就沿用 Soldier，不浪费。

## 三、网页操作步骤

### 1. 登录

打开 https://3d.hunyuan.tencent.com/ ，微信或 QQ 扫码登录。
每天有 **10 次免费生成次数**，邀请好友可增加。

### 2. 图生 3D（男主先做）

1. 左侧功能栏选「**图生3D**」
2. 上传 `人物候选图/hero_v3_realistic.png`
3. 点「立即生成」，默认一次出 **4 个模型，只扣 1 次额度**
4. 等约 1 分钟，在线预览 4 个结果，**重点看正反面和侧面**
5. 挑质量最好的一个

### 3. 骨骼绑定 + 动画（关键）

> 这一步不能跳过。没有动画的模型接入游戏后人物无法走动。

1. 进入「**实验室**」功能，找「**骨骼绑定** / 3D 动画生成」
2. 对选中的模型做自动绑骨（biped 人形）
3. 生成动画：`idle`（待机）、`walk`（走）、`run`（跑）
4. 预览动画，确认没有严重穿模/变形

> 如果实验室的动画功能要会员或效果太差，就只导出静态模型，动画我这边用现有 Soldier 的动作数据重定向过去（需要额外适配）。

### 4. 导出 GLB

1. 在线预览确认满意后，点「导出 / 下载」
2. 格式选 **GLB**（通用 3D 格式）
3. 保存到：`web/public/models/characters/hero_ai.glb`
   - 女主对应：`web/public/models/characters/heroine_ai.glb`
   - 完整路径：`C:\Users\Administrator\Desktop\新开发\精灵物语\web\public\models\characters\`

## 四、生成完成后交给我做接入

把 GLB 放到上面的目录后，回复我一声。我会做这些适配：

1. **识别动画名**：读取模型内的 animation clip 名字，映射到引擎的 `Idle / Walk / Run`
2. **贴地**：确认模型原点在脚底，不浮空、不陷地（SkinnedMesh 不能用 Box3 归一化）
3. **朝向修正**：Soldier 默认面朝 -Z，新模型需重新确认默认朝向，调整 `moveAngle` 修正角
4. **尺寸对齐**：缩放到和场景/现有角色一致
5. **材质保留**：克隆材质时保留纹理，不要让写实贴图丢失
6. **E2E 验证**：跑 `_e2e_interact.js` + 截图确认走路/朝向/贴地效果

需要的话我会保留 Soldier 作为回退（`hero.glb` 不删，新模型命名 `hero_ai.glb`），随时能切回去。

## 五、如果效果不满意

直接沿用现有 Soldier 模型，不动代码。后续可选方向：

- **贴图烘焙过渡**：把 AI 人物图处理成贴纸/皮肤风格套到 Soldier 上（零成本，质感提升有限）

- **统一卡通风**：全项目角色统一成 Kenney 卡通风，牺牲写实但风格统一
