# Mixamo 自动绑骨 + 动画操作指引（男主模型）

> 目标：给 AI 生成的男主静态模型加上骨骼和 idle/walk/run 动画,让它能在游戏里走动。
> 前提：男主模型外观已确认过关（质感优于现有 Soldier）,但混元3D 只能出静态模型,无骨骼无动画。
> Mixamo 是 Adobe 免费服务,自动绑骨 + 大量现成动画,无需会员。

---

## 一、先讲清楚风险（决定是否值得做）

Mixamo 自动绑骨对 AI 生成模型的两个已知短板：

1. **长披风**：这个模型有及地长披风。自动绑骨会把披风当身体一部分刚性绑定,走路时披风**可能像硬板子跟着身体漂**,不会自然摆动。
2. **手指/细节**：AI 生成的模型手部结构可能不标准,自动绑骨后手指动画可能异常（但游戏远景一般看不出来）。

**建议**：按下面步骤做到第 4 步看 Mixamo 的动画预览,披风能接受再下载,不能接受就停止,别浪费时间。

## 三、操作步骤

### 1. 登录

打开 https://www.mixamo.com/ ,用 Adobe 账号登录（没有就免费注册一个,不需要付费会员）。

### 2. 上传模型

1. 点左侧 **Upload Character**
2. 选 **Upload OBJ or FBX**,把 `Mixamo上传包/character.obj` 拖进去
3. 等上传 + 自动识别人形（约 1-2 分钟）

### 3. 自动绑骨（Rigging）

上传后会进入绑骨界面,关键点：

- **动画类型**：选 **In Place**（原地动画,游戏里人物靠代码移动,不需要 root motion 位移）
- **关节定位**：Mixamo 会自动放置关节点。仔细检查：
  - 头部、肩膀、手肘、手腕位置是否对准
  - 膝盖、脚踝是否对准
  - 如果明显错位,手动拖动关节点对齐（这一步对最终效果影响很大）
- 确认后点 **Finish**,等自动绑骨完成

### 4. 选动画 + 预览（关键决策点）

绑骨完成后,在动画库里搜并依次试：

- `Idle`（待机）
- `Walking`（走）
- `Running`（跑）

点进去看右侧预览：

- **重点看披风**：走路/跑步时披风是否像硬板子、有没有严重穿模
- 看手臂/腿部动作是否自然、有无扭曲

**如果披风效果完全不能接受 → 停止,告诉我,我们换方案。**
**如果能接受 → 继续下一步下载。**

### 5. 下载 FBX

对选中的每个动画点 **Download**,设置：

- Format：**FBX**
- Keyframe Reduction：默认即可
- 三个动画分别下载：`idle.fbx` / `walk.fbx` / `run.fbx`

## 四、下载后交给我做接入

把 3 个 FBX 放进 `Mixamo上传包/output/` 后回复我一声。我会做：

1. **FBX → GLB 转换**：用工具链把带骨骼动画的 FBX 转成 GLB（three.js 能直接加载的格式）
2. **贴图重新贴合**：Mixamo 导出的 FBX 可能带自己的材质,我把原来的写实质感贴图贴回去
3. **动画名映射**：识别 idle/walk/run,映射到引擎的 `Idle / Walk / Run`
4. **贴地 + 朝向 + 尺寸**：确认脚底贴地、朝向跟随移动方向、尺寸对齐场景
5. **E2E 验证**：跑 `_e2e_interact.js`,截图确认走动/朝向效果

> 如果 FBX 转换遇到工具链问题,我会想办法（装转换库或走 Python 路线）,这部分你不用操心。

## 五、备选方案（如果 Mixamo 效果不行）

- **静态模型接入**：人物先不动或用简单位移,保留写实质感,动画以后再说
- **沿用 Soldier**：放弃这个模型,继续用现有带动画的 Soldier
- **披风问题规避**：如果有建模工具,可以把披风从模型里分离出来单独做布料模拟（成本高,暂不建议）
